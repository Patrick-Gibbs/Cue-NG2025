# LTPI: interactive figures

Interactive slides explaining LTPI (liability threshold phenotypic integration) from
Lee et al., "Liability threshold model-based disease risk prediction based on electronic health record phenotypes",
*Nature Genetics* 57, 2872–2881 (2025).

Open `index.html` in a browser, or view it on GitHub Pages. Use the arrow keys to move between slides and **F** for full screen.
